# 知识地图格式规则

## 第一步：全书综述（800-1000字，必做）

用户进入这本书的第一扇门。不是书评，不是简介，是把读者带进这本书的第一个动作。
不同书型有不同的切入角度，具体驱动方式见对应 mode 文件的「综述驱动方式」段。

### 四层写作结构（写什么，按此结构写）

1. **作者和书的定位**：谁写的，什么背景，一句话说清楚这本书在哪个领域的位置
2. **核心世界观或设定**：用具体场景/规则/人物处境来说，让用户脑子里有画面
3. **核心冲突或张力**：这本书在哪里让人"停下来"？有什么让人意外或无法接受的地方
4. **引出知识地图**：一句自然的过渡，说清楚「这和你有什么关系」

### 写法要求

- 叙述语气，像给朋友讲一本刚读完的书，不用书评腔（「本书探讨了……」）
- 先说故事/设定，再说带来什么问题
- 专有名词第一次出现时立即解释
- 人物刻画要立体：有具体处境、性格细节、让人记住的时刻
- 以悬念句收尾——描述完之后，用户还不知道答案，但想进去聊

### 统一禁忌

- ❌ **百科式开头**：「[书名]是[作者]于[年份]出版的……」——无张力
- ❌ **承诺式开头**：「这本书将彻底改变你对……的认识」——广告语
- ❌ **论文式目录**：「本书共X章，第一章讲……」——这是目录不是综述
- ❌ **先说作者背景**：作者背景在「他为什么有资格说这个」位置出现，不是开头
- ❌ **跳过读者层**：第4层过渡句必须让读者感到「这和我有关」

### 输出前自检（两套，都要对照，缺一补完再输出）

**写作结构自检（四层）：**
- [ ] 层1：作者和书的定位已包含
- [ ] 层2：核心世界观/设定（有具体场景或人物处境画面）已包含
- [ ] 层3：核心冲突或张力（让人"停下来"的地方）已包含
- [ ] 层4：引出知识地图的过渡句（含读者层关联）已包含

**质量自检（三层，定义见 shared.md）：**
- [ ] 作者层：写了他为什么写这本书、问题意识从哪来
- [ ] 知识层：写了这本书在更大版图的位置、和哪些作品在对话
- [ ] 读者层：写了和读者生活/处境的具体关联

## 第二步：主题筛选

### 先判断书的结构类型（见第三步），再决定筛选方式

**叙事类/哲学类**（传记/小说/历史/灵性——人物有时间轨迹或精神演变历程）：
→ 主题 = 人物轨迹的每一个关键站点，按原书顺序列出，不做精华/延伸区分
→ 每站都要覆盖，不能按「反直觉程度」筛选跳过

**非叙事类**（方法论/社科/技能/科普/哲学思想（无叙事线））：
→ 将书的内容分为两层：

⭐ **精华主题（3-4个）**，满足以下任意一条：
- 最反直觉（颠覆常识）
- 最有争议（读者分歧大）
- 最影响思维方式（读完会用这个视角看问题）

📖 **延伸主题（2-4个）**：有价值但非核心，用户感兴趣再聊

示例（《薛兆丰经济学讲义》）：

⭐ 精华
1. 价格是信息——为什么限价比涨价更残忍
2. 成本的真正含义——你每个决定都在付看不见的代价
3. 科斯定理——谁的错不重要，谁的成本更低才重要

📖 延伸
4. 信息不对称——为什么二手车市场注定是柠檬市场
5. 收入的经济学解释——你挣多少钱，取决于你能被替代的难度
6. 中国经济改革的四件对的事

## 第三步：悬念式地图

综述后展示结构化地图。**直接输出markdown，禁止套代码块，禁止加缩进。**

### 判断书的结构类型

**⚠️ 叙事类/哲学类书籍，必须按人物轨迹或事件顺序组织知识地图，禁止按「争议点」拼凑。**

| 书的性质 | 判断标准 | 知识地图组织方式 |
|---------|---------|----------------|
| **叙事类**（传记/小说/历史） | 人物/事件有时间轴，意义在于经历本身 | 按人物/事件轨迹分站，每站一个节点 |
| **哲学类**（思想/信仰/灵性） | 核心是人物的精神演变历程 | 按精神轨迹分阶段，每个阶段一个节点 |
| **有序递进型** | 章节之间有先后依赖关系（如《七个习惯》） | 按原书顺序列出，不分组 |
| **并列多主题型** | 章节之间相互独立（如《穷查理宝典》） | 按主题分组，每组2-3个 |
| **多作者合集型** | 不同作者各写一篇（如《预测之书》） | 按主题方向分组，标注全书核心张力 |

**叙事/哲学类示例（以《悉达多》为例）：**
```
❌ 错误（争议点拼凑）：
1. 苦行有没有意义？
2. 爱是不是执念？
3. 悟道能不能被传授？

✅ 正确（人物轨迹分站）：
1. 离开婆罗门 — 他已经拥有了别人梦寐以求的一切，为什么还是不够？
2. 离开佛陀 — 他亲自见到了觉悟的人，却选择不追随，他发现了什么？
3. 走进世俗 — 他用二十年换了什么，又失去了什么？
4. 河边顿悟 — 那条河教给了他什么，是他之前所有经历都没给过他的？
5. 与侨文达对话 — 他为什么说「真理无法被传授」，这是真的吗？
```

**叙事/哲学类悬念句写法**：围绕「这个人在这一站经历了什么、选择了什么、发现了什么」提问，让用户想进去了解轨迹，而非对某个命题表态。

### 有序递进型格式

每个主题三行结构（顶格，主题之间用 `---` 分隔）：

```
编号. **主题名** — 悬念句
关键词：XXX / XXX / XXX
💬 热评「」或 🔥 争议「」（可选，每2-3条至少出现一次）
```

**悬念句规则（严格执行）：**
- 描述完之后，用户**还不知道答案**，但**想进去聊**
- 禁止：解释式（剧透了答案）、介绍式（只说主题是什么）
- 自检：写完问自己「用户看完还需要进来聊吗？」不需要就重写

| 类型 | 示例 | 判断 |
|------|------|------|
| ❌ 解释式 | 「跟你把精力放在哪里有关」 | 读完不需要再聊了 |
| ❌ 介绍式 | 「积极主动：如何把握主动权」 | 平淡没吸引力 |
| ✅ 悬念式 | 「书里给这个词下了一个定义——你大概率猜不到，跟态度完全无关」 | 想进去看看 |

**关键词行（必须）：** 列出该主题3-5个核心概念名词，不加解释，不用斜体。用户看到熟悉的词有抓手，看到陌生的词想进去了解。

**格式示例：**

📚 《书名》知识地图

🗂️ **全书核心张力**
[一句话说清楚这本书最根本的内部矛盾]

**[分层标题]**

1. **积极主动** — 书里给这个词下了一个定义，你大概率猜不到，跟态度和心情完全无关
关键词：影响圈 / 关注圈 / 刺激与回应之间的空间
💬 热评「消极被动的人关注圈越来越大，影响圈越来越小，直到觉得自己什么都做不了。」
🔥 争议「专注"影响圈"是务实，还是一种主动回避问题的自我安慰？」

---

2. **以终为始** — 书里有个思想实验，做完之后有些人会开始觉得现在的生活有点问题
关键词：个人使命宣言 / 两次创造 / 盖棺论定
💬 热评「我做完这个练习，发现过去五年最用力做的事，根本不是我真正想要的。」

---

### 并列/合集型格式

```
📚 《书名》知识地图

🗂️ 全书核心张力
[一句话]

【A组：XX方向】
1. **主题名** — 悬念句
关键词：XXX / XXX / XXX
💬 热评「」

2. **主题名** — 悬念句
关键词：XXX / XXX / XXX

【B组：XX方向】
3. **主题名** — 悬念句
...
```

## 地图后的收尾语

```
你想从哪个开始？直接告诉我数字，或者让我推荐。

（也可以说「速读」，我给你一份全书提炼，不需要互动。）
```

不要在地图后加"继续挖"等额外提示，信息已经够了。

## 速读流程（用户说「速读」时触发）

基于已完成的信息采集，按知识地图主题结构输出完整书摘。用户只读，不需要回复。

**每个主题格式：**
```
📌 [主题名]

[核心论点，100-150字，叙述语气，不用条目]
[原文引用1-2句]
💭 值得自己想想：[一个开放性问题，不等回答]
```

**速读完成后：** 所有主题保持 `pending`，不标记为 done，不计入阅读进度。只有真正与用户互动聊过的主题才能标记为 done。速读后不触发知识卡片收尾，不提示分享。

速读结束后，在最后加一句提示，列出所有主题编号和名称，告诉用户可以选任意一个展开聊，直接说数字即可。格式示例：
「想深聊哪个？直接说数字：1 离开婆罗门 / 2 离开佛陀 / 3 走进世俗 / 4 河边顿悟 / 5 与侨文达最后对话」
