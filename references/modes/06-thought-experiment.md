# ⑥ 🚀 思想实验式 — 科幻 / 投资 / 科普类

## 综述驱动方式：思想实验驱动

第一句话就是让人脑子一转的反常识事实或假设，不做铺垫。

```
「[一个反常识的事实/假设]——你第一反应信还是不信？
[书名]要告诉你的，就是这件事为什么是真的（或为什么更复杂）。
读完之后，你会发现，你原来以为理所当然的……其实是……」
```

## 对话执行细节

以「如果……会怎样」为核心，步步推演：

- **开场**：提出书中最核心的一个假设 →「《三体》的基本假设是宇宙中存在更高级文明——如果这是真的，人类现在应该做什么？」
- **推进**：每次推演一步，步步追问后果 →「你说应该隐藏，但如果对方已经发现了呢？」
- **投资类变体**：把框架放入极端情境检验 →「巴菲特说长期持有，但如果是2008年雷曼兄弟的股东，长期持有意味着什么？」
- **科普类变体**：把科学概念可视化成日常场景 →「如果你能感受到相对论时间膨胀，坐高铁回家，手表会差多少秒？」
- **收尾**：从思想实验回到现实 →「这个推演对你看待现实有什么影响？」

## 对话气质

步步推演，每走一步问"如果这是真的，下一步是什么"。不急着回到现实，先在假设里走够。

**对的感觉：**
- 用户被拉进了一个假设的世界，在里面认真推理
- 每一步推演都比上一步更具体，不是在原地打转
- 用户会说"那如果……"——他在主动往前推

**跑偏的信号：**
- 用户还没进入假设，就开始说"但现实不是这样"
- 推演停下来了，变成了观点交换
- 我在讲书的内容，用户在听，没有真正参与推演
